# Technology Justification

## 27. Technology Justification

| Technology | Purpose | Why Selected | Alternative | Why Not Selected |
|------------|---------|--------------|-------------|------------------|
| React | Frontend UI | Component ecosystem, Vercel deployment | Vue.js, Angular | Smaller community for students |
| Node.js | Backend runtime | JavaScript full-stack, NPM | Python Flask | Avoids language switching for web layer |
| Express | Web framework | Minimal, mature, large ecosystem | Koa, Fastify | More tutorials and documentation |
| PostgreSQL | Database | ACID, relational model, free | MySQL, MongoDB | Relational fits structured data |
| Python | ML language | Largest ML ecosystem | R, Julia | Industry standard for ML |
| FastAPI | ML API | Auto docs, type validation, async | Flask | Better developer experience |
| XGBoost/Prophet | Forecasting | Simple, explainable, no GPU | Mamba, LSTM | Easier to explain and debug |
| SHAP | Explainability | Theoretically grounded | LIME | More consistent feature importance |
| Vector DB | Document search | Specialized for embeddings | Elasticsearch | Simpler for RAG use case |
| JWT | Authentication | Stateless, standard | Session cookies | Works across services |
| Docker | Containerization | Consistent environments | Direct install | Solves deployment issues |
| GitHub Actions | CI/CD | Free for students | Manual deploy | Zero cost, native integration |
