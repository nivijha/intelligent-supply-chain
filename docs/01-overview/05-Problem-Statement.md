# Problem Statement

---

## 3. Problem Statement

### 3.1 Precise Problem Statement

Existing supply-chain systems often provide operational visibility but do not effectively combine demand forecasting, inventory analysis, warehouse information, and knowledge from official documents into a single explainable decision-support workflow.

### 3.2 Detailed Problem Description

Public-sector food supply-chain systems in India currently operate with:

- **Fragmented data access:** Operational data exists across multiple systems (FCI, DFPD, state portals) without unified access
- **Manual interpretation:** Decision-makers manually interpret reports and make allocation decisions without analytical support
- **No forecasting capability:** Existing systems display current and historical data but do not predict future demand
- **No integrated recommendations:** There is no automated mechanism to translate data into actionable suggestions
- **Limited explainability:** When predictions or analyses are provided, the factors driving them are not transparent
- **Disconnected knowledge:** Official policies, guidelines, and circulars exist as separate documents not linked to operational decisions

### 3.3 Consequences

The absence of an integrated decision-support system leads to:

- Reactive rather than proactive inventory management
- Stockouts at distribution points while warehouses hold excess stock
- Suboptimal allocation of commodities across warehouses
- Decision-makers relying on intuition rather than data-driven insights
- Difficulty justifying allocation decisions to oversight bodies
- Inconsistent application of official guidelines across regions

### 3.4 Scope of Problem

The problem is scoped to:

- Decision-support (not autonomous execution)
- Prototype implementation (not production-scale deployment)
- Selected commodities (not the entire PDS spectrum)
- Official government data (not real-time IoT or private-sector data)
- Indian public-sector context (not global supply chains)

### 3.5 Not Claimed

This project does not claim:

- That no existing system provides any form of analytics
- That the problem is entirely unsolved in the industry
- That our solution is superior to all existing approaches
- That the system is ready for production deployment

The contribution is an integrated prototype combining established techniques into a focused decision-support workflow for the Indian public food supply-chain context.
